# NOTE on Mamba.
# The official CUDA package is NOT listed here on purpose. `pip install mamba-ssm`
# is a source-only distribution whose build requires the CUDA Toolkit (nvcc) and
# is not officially supported on Windows; on this machine it failed with
# "nvcc was not found". src/mamba_ref.py therefore vendors the official
# *reference* (non-fused) implementation from state-spaces/mamba, which computes
# the same function without compilation. If you are on Linux with nvcc available,
#     pip install mamba-ssm --no-build-isolation
# is picked up automatically by src/mamba_ref.build_mamba_block and the backend
# reported in every artifact changes to "mamba_ssm_cuda".
